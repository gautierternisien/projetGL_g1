# Projet Génie Logiciel

Voici comment lancer le projet avec Vue3 et Fastapi

## Lancer le backend
Mettez vous dans un terminal
```sh
cd .\backend\
```

```sh
fastappi dev .\main.py
```

## Lancer le frontend
Mettez vous dans un autre terminal
```sh
cd .\frontend\
```

```sh
npm run dev
```

## Problème courants

S'il vous manque des objets vuetify faite dans le frontend un :
```sh
npm ì
```
